# ❤️ HeartLED-GIFT

A heart-shaped LED matrix built around the STM32F103.

## Features

- ❤️ I LOVE YOU animation
- ❤️ Static heart
- ⭐ Starfall
- ☄️ Random comet
- 🔘 Button mode switching
- ⚡ SPI communication using 74HC595
- 💡 Software PWM brightness control

## Hardware

- STM32F103C8T6
- USB Type-C
- Li-ion charging
- Custom PCB
- 74HC595 shift registers
